## 기업 연계 프로젝트 경험

### 모비데이즈 기업 연계 프로젝트

**참여 기업:** 모비데이즈는 퍼포먼스 마케팅과 콘텐츠 유통을 전문으로 하는 디지털 마케팅 에이전시로, 국내외 다양한 브랜드의 마케팅 전략 수립부터 실행까지 전 과정을 담당하고 있습니다.

**진행 방식:** 팀 단위 실무 협업 프로젝트로, 모비데이즈의 실제 데이터를 AARRR 퍼널 관점에서 분석하고 획득(Acquisition) → 활성화(Activation) → 매출·전환(Revenue) 단계를 가설 수립 → A/B 테스트 → 성과 개선 흐름으로 2차에 걸쳐 수행하였습니다.

**1차 — 거래소 실시간 데이터 분석 프로젝트 (104시간)**
- DMQ 자격증 채널별 유입 데이터를 분석하여 전환 인사이트를 도출하였습니다
- 타겟별 메시지·소재 가설을 수립하고 A/B 테스트를 설계하였습니다
- 채널·디바이스·콘텐츠별 클릭률을 분석하고 메타·구글·네이버 광고 소재 실험을 수행하였습니다
- 통계 검증을 통해 인사이트를 도출하고 리포트로 정리하였습니다

**2차 — 마케팅 전략 개발 프로젝트 (160시간)**
- 1차 분석 인사이트를 기반으로 마케팅 전략을 수립하고 디지털 광고 전략 제안서를 작성하였습니다
- 광고 소재를 기획·제작(A/B 테스트 포함)하고 실제 광고 캠페인을 세팅·운영하였습니다
- 성과 데이터를 분석하여 예산을 재배분하고 매체를 최적화하였습니다
- 기획 → 제작 → 운영 → 분석을 아우르는 실전 광고 운영 역량을 갖추었습니다

**활용 도구:** Gemini, 피그마, GA4, Beusable, Meta 광고 관리자 등 디지털 매체

## 인턴십

**멋쟁이사자처럼 그로스 마케터 정규직 전환형 인턴십** (우수 수료생 대상)

- **셀프서빙 매체 운영 보조** — Meta·Google·Naver 등 광고 플랫폼에서 직접 캠페인을 세팅하고 예산을 운영하며 퍼포먼스 개선에 기여하였습니다
- **데이터 기반 성과 분석 및 개선** — 광고 운영 후 캠페인 성과 데이터를 바탕으로 개선 방향을 수립하고 인사이트를 도출하였습니다 (Meta·Tableau·Looker Studio 활용)
- 데이터 분석으로 성과를 개선하는 전 과정을 경험하며 문제 해결력과 캠페인 실무 역량을 갖추었습니다

## 취업 연계

- **자격증 취득 지원** — 강사진 직강 DMQ 자격증 대비 특강과 응시료 지원, SQLD 자격증 VOD 강의를 활용하여 직무 자격 역량을 강화하였습니다
- **실무형 포트폴리오** — 모비데이즈 실데이터 기반 그로스 마케팅 프로젝트 결과물(DMQ 클릭률 개선·마케팅 성과 개선), GA4·GTM·Looker Studio 마케팅 대시보드, Python·머신러닝 데이터 분석 리포트를 포트폴리오로 완성하였습니다
- **커리어 로드맵** — 수료 직후 데이터 분석 기반 그로스 마케팅 포트폴리오를 완성하고, 정규직 전환형 인턴십을 통해 실무 협업 경험과 취업 연계를 확보하여 퍼포먼스 마케터 → 그로스 마케터 → 그로스 마케팅 리드·마케팅 데이터 분석가로 이어지는 성장 경로를 설계하였습니다

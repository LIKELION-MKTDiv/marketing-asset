## 부트캠프 교육 이수 내역

### 멋쟁이사자처럼 AWS 클라우드 엔지니어링 부트캠프 8기

**교육 기간:** 약 22주 (STEP 1~6, 1~22주차) / 실전 프로젝트 3회 + 단독 인턴십

| 단계 | 주차 | 교육 내용 | 핵심 스킬 |
|---|---|---|---|
| STEP 1 — Java 기반 백엔드 개발 + 데이터베이스 + Spring Boot | 1~6주차 | Java 기초·심화(객체지향·함수형·동시성), 관계형 DB·정규화·SQL·JDBC, HTML/CSS·JavaScript ES6·비동기, Git 브랜치 전략·협업, Spring Boot(DI/IoC·MVC·JPA·REST API·인증/인가·캐싱), 커뮤니티 게시판 풀스택 구현 | Java · MySQL · Spring Boot · JPA · Redis · GitHub |
| STEP 2 — 리눅스·Docker 기반 인프라 기초 + AWS 입문 | 6~9주차 | 네트워크(TCP/IP·OSI 7 Layer·DNS), 리눅스 OS·가상화·Shell 프로그래밍, Docker 이미지·컨테이너·Dockerfile·멀티 컨테이너, 클라우드 컴퓨팅 개념과 AWS 핵심 서비스(VPC·EC2·S3·IAM) | Linux · Docker · AWS |
| STEP 3 — [PROJECT 1] 클라우드 아키텍처 설계 실습 | 9~10주차 | 요구사항 분석 및 서비스 시나리오 작성, AWS 서비스 조합 설계, 아키텍처 다이어그램 작성·검토, 설계 발표 및 피드백 | AWS · Draw.io · Notion |
| STEP 4 — AWS 클라우드 엔지니어링 실무 심화 | 10~16주차 | AWS 네트워크(VPC·Route 53·CloudFront)·컴퓨팅(EC2·Lambda)·데이터(RDS·DynamoDB·S3)·보안·고가용성, DevOps와 CI/CD(GitHub Actions), Kubernetes 클러스터 구축·운영, IaC(Terraform)·GitOps(ArgoCD), 모니터링(CloudWatch·Prometheus·Grafana) | AWS · Kubernetes · Terraform · GitHub Actions · ArgoCD · Prometheus · Grafana |
| STEP 5 — [PROJECT 2] AWS 인프라 구축 + 컨테이너 운영 | 16~17주차 | VPC·EC2·EKS 기반 인프라 구축, CI/CD 파이프라인 적용, Terraform IaC 자동화, 모니터링·로깅 환경 구성, 구축 결과 발표 및 코드 리뷰 | AWS · Terraform · Kubernetes · GitHub Actions |
| STEP 6 — [PROJECT 3] 하이브리드 클라우드 운영 시스템 구축 | 17~22주차 | 백엔드 서비스와 AWS 인프라 통합, 멀티 클러스터 Kubernetes 운영, CI/CD와 GitOps 적용, 모니터링·로깅·자동화 시스템 구축, 장애 대응·트러블슈팅 실습, 실서비스 수준 운영 시연 | AWS · Kubernetes · Spring Boot · Terraform · ArgoCD · GitHub Actions |

**교육 특징**

- 개발 → 배포 → 운영 → 보안으로 이어지는 Full-Cycle 커리큘럼을 이수하여, 구축을 넘어 개발·배포·운영까지 이해하는 클라우드 엔지니어 역량을 갖추었습니다
- 이론 → 실습 → 회고로 이어지는 학습 순환과 TIL 챌린지를 통해 학습 내용을 매일 기록하고 포트폴리오 자산으로 축적하였습니다
- 실시간 AI 노트와 MILO 모닝 브리프를 활용하여 강의 내용을 정리하고 복습 효율을 높였습니다

## 멘토링 및 지원 프로그램

**현업 전문가 멘토링**
- 클라우드 인프라·데이터·DevOps 분야 현업 AWS 전문 멘토진의 밀착 피드백을 받으며 프로젝트를 수행하였습니다
- 강사진 1:1 밀착 케어와 실시간 피드백, 매월 학습 현황 리포트를 통해 학습 상태를 점검하고 보완하였습니다

**학습 케어 프로그램**
- 이론 → 실습 → 회고로 이어지는 학습 순환 구조에서 배운 내용을 바로 실무에 적용하며 문제 해결 역량을 길렀습니다
- 실시간 AI 노트, MILO 모닝 브리프, TIL 챌린지를 활용해 매일 학습을 정리하고 회고 기록을 포트폴리오 자산으로 축적하였습니다
- 전문 매니저 1:1 상담을 통해 개인별 학습 전략을 설계하였습니다

**실무 환경 지원**
- 팀 프로젝트 기간 중 AWS 클라우드 리소스를 지원받아 실제 클라우드 환경에서 인프라를 구축·운영하였습니다
- 백엔드·웹/앱 개발·코딩테스트·정보처리기사·SQLD 등 실무 VOD 강의를 활용해 학습 범위를 확장하였습니다

## 인턴십

**멋쟁이사자처럼 수료생 한정 단독 인턴십**

현업과 동일한 워크플로우로 기획자, 프론트엔드·백엔드 개발자, 디자이너 등 다양한 직군과 실무 프로젝트를 처음부터 끝까지 수행하였습니다.

- **아키텍처 기획 및 설계** — 트래픽·가용성·보안 관점에서 서비스 요구사항을 분석하고 VPC·네트워크·보안 구조를 정의한 클라우드 아키텍처를 설계하였습니다
- **인프라 구축 및 배포 환경 구성** — AWS 인프라를 구축하고 컨테이너 실행 환경을 구성하여 서비스 배포 기반을 완성하였습니다
- **운영 및 자동화** — 모니터링·로그 기반으로 운영을 관리하고 장애에 대응하였으며, CI/CD를 구축하여 배포를 자동화하였습니다
- **프로젝트 마무리** — 운영 결과를 점검하고 비용·보안을 최적화하였으며, 아키텍처 설명을 정리해 포트폴리오로 완성하였습니다

## 취업 연계

- **미래내일 일경험** — 고용노동부 지원 사업의 공식 운영 기관인 멋쟁이사자처럼에서 100개 이상 테크 기업 채용 협약을 기반으로 한 취업 연계 프로그램에 참여하였습니다
- **자격증 취득** — AWS SAA(Solutions Architect Associate) 자격증 합격 시 응시료를 지원받는 프로그램을 통해 클라우드 직무 자격 역량을 강화하였습니다
- **커리어 서포트 플랜** — 개강부터 종강까지 전문 커리어팀과 목표 기업 설정, 채용 공고 분석, 서류·면접 대비를 진행하였습니다
- **커리어 로드맵** — 수료 직후 백엔드·AWS 인프라·하이브리드 클라우드 구축을 아우르는 Full-Cycle 포트폴리오를 완성하고, 단독 인턴십을 통한 실제 서비스 운영 경험으로 클라우드 엔지니어 → DevOps 엔지니어 → 인프라·플랫폼 엔지니어로 이어지는 성장 경로를 설계하였습니다

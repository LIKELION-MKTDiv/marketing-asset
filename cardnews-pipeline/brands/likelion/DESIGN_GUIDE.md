# 멋쟁이사자처럼 인스타그램 카드뉴스 디자인 가이드 (brand.json 근거)

출처: BE 「인스타그램 콘텐츠 제작 공통 가이드」(2026-08-12 팀 리뷰), LIKELION BRAND GUIDELINE(컬러·로고 여백), Pretendard 실측.

## 1. 확정 스펙 (전사 공통, 콘텐츠 사정으로 바꾸지 않음)

| 항목 | 값 | brand.json |
|---|---|---|
| 규격 | 1080 × 1350px (4:5) | `canvas` |
| 여백 | 상하좌우 100px, 사용 폭 880px, 좌측 기준선 x=100 | `safe_area` |
| 서체 | Pretendard | `fonts` |
| 썸네일(커버) | 메인 90~100px / 서브 35~40px | `type.cover` 90, `type.cover-sub` 40 |
| 내용 | 메인 65px 더 굵게(ExtraBold) / 서브 35px | `type.h`, `type.sub` |
| 아웃트로 | 메인 70px / 서브 35px | `type.outro`, `type.outro-sub` |
| 로고 | 중앙 하단, 잉크 188 × 21px, 아랫단 y=1250 | `logo.ink_width` 188, `logo.bottom` 100 |
| 로고 색 | 어두운 배경 → 흰색 / 오렌지·밝은 배경 → 검정 | spec `logo` |
| 로고 여백 | 사방 최소 0.2X | (눈 검수) |

여백 100px는 프로필 그리드 3:4 크롭 안전선(84px)을 포함합니다.

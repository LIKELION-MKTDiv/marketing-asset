### [TRY-10] 성장 지표 재정의 파일럿
| | |
|---|---|
| **출처** | L1 / 3F-8 웍스피어 |
| **적용 라인** | `KDT` `KDC` |
| **그들의 문제** | 총 지원 수 = 지원자 수 × 1인당 지원 횟수. **"100명이 1번씩 지원한 100건"과 "10명이 10번씩 지원한 100건"은 대시보드에서 같은 100건** |
| **그들이 한 것** | 기준 변경 — **지원 수 → 유니크 지원자 수**, **지원 건당 비용 → 첫 지원자 1명당 비용** |
| **결과** | CPA가 20~30%가 아니라 **몇 배 나빠 보임**. "효율이 나빠진 게 아니라 우리가 보던 숫자가 더 정확해진 것" |
| **멋사 변환** | 모집 리포트에 **신규(첫 지원) 지원자 수**와 **신규 지원자 획득 단가**를 병행 표기 |
| **⚠️ 사전 합의 필수** | 지표를 바꾸면 숫자가 나빠 보인다. **"쉬운 전환을 걷어내야 새로 만든 성장이 보인다"** 는 것을 리더십과 먼저 합의할 것 |
| **첫 실험 크기** | **1개 기수 모집 사이클 / 병행 측정** |
| **성공/실패 기준** | 신규 지원자 절대 수가 증가하는가 (총 지원 수가 줄더라도) |

### [TRY-19] JSON-LD 구조화 데이터 점검 및 적용

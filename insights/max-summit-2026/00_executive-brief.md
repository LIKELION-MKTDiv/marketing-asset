## 한 문단 요약

서밋의 합의는 **"AI를 쓰자"가 아니라 "AI에게 읽히는 구조를 만들고, AI가 못 하는 판단을 사람이 하자"** 였습니다. 리더 대상 조찬 세션에서 나온 숫자가 이를 압축합니다 — **직장인 87%가 AI를 쓰고 75%가 더 생산적이라 느끼지만, 회사 성과가 좋아졌다고 답한 곳은 13%뿐입니다.** 그리고 그 간극의 원인은 개인이 아니라 **회사 쪽에 2/3**가 있습니다.

**v2에서 이 진단이 더 무거워졌습니다.** 추가된 7개 세션 중 5개가 독립적으로 같은 결론에 도달해, **"개인은 빨라졌지만 조직은 아니다"가 교차검증 12로 서밋 전체의 단독 최대 합의**가 되었습니다. 그리고 그 세 실패담의 공통 구조는 **"안 쓴다"가 아니라 "쓸 수 있는 형태로 주지 않았다"** 였습니다.

## 🆕 v2 신규 관찰 — 콘텐츠 제작의 경제 구조가 바뀌었다

> 기존 5 Bets 어디에도 담기지 않는 축이라 별도로 둡니다. 자세한 내용은 `01_트렌드-통합관점.md` **명제 7**.

**진단 프레임 하나만 가져가면 됩니다 — 우리가 콘텐츠를 못 만드는 이유는 셋 중 무엇인가?**

| 벽 | 정의 | 예산이 필요한가 |
|---|---|---|
| **① 비용의 벽 (Production Tax)** | 기획·촬영·편집·CG·VFX·사운드 전 공정에 붙는 필수 비용 | 예 — 그러나 AI로 급감 중 |
| **② 속도의 벽 (리드타임)** | 캠페인 하나에 수 주~수 개월. 그러고 나면 트렌드는 이미 지났다 | **아니오** |
| **③ 확장성의 벽 (채널 폭발)** | 필요량은 10배인데 제작 방식은 수년 전 그대로 | **아니오** |

- **핵심 진단**: 콘텐츠를 도입하지 못하는 이유 1위는 **시간도 비용도 아닌 "만들 수 있는 역량"**(D1-11). 그렇다면 우리 처방은 **외주 확대가 아니라 툴 학습**입니다
- **우리와 구조가 같은 사례 — 현대자동차**: 현대차가 요구한 것은 "영상을 잘 만들어 줘"가 아니라 **"글로벌 가이드라인이 깨진다"** 였습니다. 지역·딜러마다 제각각 만들어 브랜드 아이덴티티가 붕괴. **우리도 KDT/KDC/기업교육/오프라인이 제각각 소재를 만듭니다.** 해법은 "하나 잘 만들면 라인·채널별로 자동 파생"되는 템플릿 구조
- **⚠️ 함정**: 제작이 쉬워졌다고 많이 만드는 것은 답이 아닙니다. **"제작 비용이 0에 수렴할수록 많은 양을 찍어내는 가치는 굉장히 약해진다"**(D1-12). 더 많은 **완성물**은 함정이고, 더 많은 **시도(시안·구도·가설)** 가 답입니다

| **R1** | **"AI 콘텐츠를 늘리면 된다"** | 모비데이즈: 2025년 이미 인터넷상 AI 콘텐츠가 사람 콘텐츠를 추월. **AI가 AI 글을 학습하는 오염** + 브랜드 할루시네이션 유발 / 크림: **AI 콘텐츠가 잘 되고 있었는데도 전략을 바꿨다.** 알고리즘이 날것을 밀어주기 시작 |
| **R2** | **"AI 사용률"을 KPI로 삼기** | 로레알 명시적 경고: **"AI를 얼마나 많이 썼는가로 기준을 잡으면 밸류는 창출 못 하고 토큰 비용만 뜬다."** → **업무 하나가 줄었는가, 맨아워가 줄었는가**로 정의할 것 |
| **R3** | **속도 개선을 성과로 보고하기** | 숙련 개발자 실험: AI 사용 쪽이 **실제로 19% 더 오래 걸렸는데 본인은 20% 빨라졌다고 체감**. **간극 40%** / 아낀 시간 주 11시간 중 **6.5시간이 검증에 되돌아감** |
| **R4** | **규정 영역을 AI에 위임하기** | 넥슨: **"AI는 책임을 질 수 없다."** 광고 자동 최적화 과정에서 **확률형 아이템 표기 누락** → 유저 고발, 게임위 손해배상 자료 제출 발생. **KDT의 훈련비·수료 요건·모집 문구가 정확히 같은 성격** |
| **R5** | **AI 답변 속 브랜드 할루시네이션 방치** | 로레알: **우리가 시키지 않았는데 우리 브랜드 이름과 함께 잘못된 정보가 나간다.** 광고는 회수할 수 있지만 **에이전트와 고객 사이의 일이라 컨트롤 밖.** → AEO/GEO 관리는 성장 과제이자 **리스크 관리 과제** |
| **🆕 R6** | **산출량을 성과로 보고하기** | NC AI가 소개한 개발사 대표: AI가 계속 작업하고 있지 않으면 불안해졌고, 결과물이 쌓이는 걸 보며 생산성이 올랐다고 느꼈으나 — **"돌아보니 산출량을 성과로 착각한 것이었다."** R3(속도)의 쌍둥이 리스크. **콘텐츠 발행 수를 KPI로 삼는 순간 같은 함정** |
| **🆕 R7** | **기준 없이 AI에 데이터 조회를 맡기기** | 엔씨소프트: App ID 기준 미정의로 **경쟁사 매출 5~6배 오차** / 컴투스홀딩스: **AI는 "만들어 줘" 하면 무조건 만들지만, 원하는 데이터가 실제로 존재하는지는 검증하지 않는다.** 애초에 API가 제공하지 않는 데이터를 "된다"고 답함 |

**🆕 R4 보강 — 규정 영역 방어법이 구체화됐습니다**
- 삼쩜삼(세무 도메인)은 **법령 사실이 틀리면 즉시 컴플라이언스 이슈**가 되는 조건이 우리와 같습니다. 대응: **생성 콘텐츠 전량에 법무 가이드가 적용된 사실 검증 파이프라인**
- LG전자는 **리걸·컴플라이언스 전용 AI 에이전트가 있음에도 자동 감지가 불안정**해 사람이 직접 확인. 특히 **AI를 언급한 콘텐츠는 반드시 사람 검토**(유럽 중심 AI 워싱 규제)
- 정복진 대표 사례의 **"3인 에이전트 회의"** 구조가 응용 가능 — 브랜드 입장 / 수강생 입장 / **컴플라이언스(훈련비·수료 요건·모집 문구) 입장** 에이전트를 각각 두고 초안을 교차 검토

### 과제 A — 머신 리더빌리티 진단 및 1차 개선
| | |
|---|---|
| **무엇** | ① `likelion.net/robots.txt` AI 봇 차단 여부 확인 ② 커리큘럼·모집 상세가 **통이미지**인지 확인 ③ **🆕 페이지 소스에 `ld+json`(JSON-LD)이 있는지 확인** ④ 브랜드 프롬프트 100회 테스트 ⑤ 상위 10개 콘텐츠 구조 리팩터링 |
| **방법** | 로레알 권고 그대로: **"카테고리에서 고객이 던질 만한 질문 20개를 만들어 5번씩 돌려보고, 우리가 얼마나 걸려 나오는지 카운팅"** |
| **🆕 진단 절차** | 컬리가 공개한 3단계를 그대로 실행 — ① `도메인/robots.txt` 직접 입력 ② `view-source:URL` 로 본문 텍스트가 소스에 있는지 ③ 소스에서 `ld+json` 검색. **컬리는 ①②는 통과했는데 ③이 없어 AI에게 거의 안 읽히고 있었음** |
| **🆕 적용 스키마 후보** | 과정 상세 = `Course` / 모집 공고 = `EducationalOccupationalProgram` 또는 `JobPosting` / FAQ = `FAQPage` |

| **성공 기준** | 브랜드명 없는 일반 질문("국비지원 부트캠프 추천") 언급률 baseline 확보 → 3개월 내 개선. **🆕 단, 컬리 사례상 점수 상승과 노출 증가 사이에 시차가 있음을 전제할 것** |
| **담당 후보** | OM + CTS |

## 이번 서밋에서 우리가 확인한 불편한 사실 하나

서밋은 AI 일색이 아니었습니다.

- 스탠리·크림 세션은 **"AI를 싹 빼고"** 시작했습니다.
- 넥슨 세션의 제목은 **"속도는 빨라졌는데, 성과는 정말 좋아졌나"** 였습니다.
- 마지막 세션(불닭·파이브가이즈)의 클로징은 **"AI 딸깍으로 완벽한 비주얼이 나올수록, 브랜드가 더 완벽함을 추구하는 건 우리가 가고 싶은 길이 아니다"** 였습니다.
- **🆕 Day1-B의 마지막 세션 제목은 「우리가 AI에게 위임하지 않은 것들」이었습니다.** LG전자는 100페이지 브랜드 가이드와 파트너사 피드백 이메일까지 통째로 학습시키고도 **"미소 짓게 하는 따뜻함을 만들어 내는 걸 AI가 정말 못 하더라고요"** 라고 결론지었습니다.

**우리가 가져와야 할 것은 "AI를 얼마나 쓰는가"가 아니라 "AI가 못 하는 것을 우리는 무엇으로 채울 것인가"입니다.**

### 🆕 그런데 v2에서 반대 신호도 하나 나왔습니다

네이버 쇼핑 AI 라이브커머스는 **"저희는 대놓고 AI스럽게 만들고 있습니다"** 라고 선언하고, 화면에 AI 표기를 한 채 **동일 조건 A/B 테스트에서 사람이 촬영한 라이브를 이겼습니다**(그 주 베스트 1위).

**모순이 아니라 영역 차이입니다.**
- **정보·제품을 파는 영역** — AI 연출을 숨길 필요가 없습니다. 숏폼에 익숙한 오디언스는 신선한 포맷으로 수용합니다
- **정서·관계를 파는 영역** — LG의 "따뜻함", 크림의 팬덤. 여기서는 여전히 위장이 필요합니다

→ **우리에게 주는 함의**: 20대 대상 모집 소재에서 **AI 제작을 숨길 필요는 없습니다.** 조건은 하나 — **사람인 척 위장하지 않기.** 반면 수료생 인터뷰·후기처럼 신뢰를 파는 콘텐츠는 다른 규칙을 적용해야 합니다.

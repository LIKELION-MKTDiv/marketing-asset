# [3F-3] 속도는 빨라졌는데, 성과는 정말 좋아졌나: 게임 UA의 AI 실전 리포트

## 한 줄 요지
속도는 AI가 가져갔다. **그럴수록 판단은 사람의 몫이 더 중요해졌고, 혼자 쓰면 개인기로 끝난다.**

## FACT — 시간 절감 (가장 구체적인 수치)
| 항목 | Before | After |
|---|---|---|
| 넥슨 UA팀 리포팅 (담당 게임 30개+) | 게임당 최소 30분 + 데이터 확인·분석 1시간 = **하루 최소 1시간 30분** | 리포팅 **자동화**, 데이터 분석 **50% 이상 감소** |
| 크래프톤 리포팅 (동일 예산·국가 기준) | 담당자 여러 명 + 파트너사, 매일 오전 2시간 → **월 약 60시간** | **월 5시간 안팎** |
| 크래프톤 캠페인 대응 | — | 이상 징후 체크 → 원인 확인 → 예산 재구축까지 **만 하루를 넘기지 않음** |
| 크래프톤 글로벌 캠페인 운영 | — | **AI 인프라 + 담당 1명**으로 소규모 캠페인 운영 가능 |

**현재 사람이 체크하는 단계는 발행 직전 이상값 확인 단 한 군데.**

## FACT — AI 소재 성과 (기대와 다른 결과)
- 넥슨 **AI 아바타 소재**: CTR은 일반 소재보다 **낮았지만** CPR **약 3배 우수**, IPM 양호 → **모객 단가 15% 개선**
- 그런데 **실제 인간 크리에이터 소재도 항상 우수하지 않음** — CTR은 높지만 CPR이 저조해 IPM·모객 단가 모두 일반 소재 대비 나쁜 경우 확인
- **결론: AI 아바타가 사람을 대체해서 좋았다기보다 기획력이 좋아야 한다는 방증**
- 게임사 사례: 아키텍트(논IP 게임)는 AI로 유료 소재 제작. **연예인 IP·스팀 타이틀은 영상·배너에 AI 미사용**, 분석·기획 용도만 — **유저 거부감 판단**
- AI 소재는 CTR·초기 노출 확보에 우수하나 **클릭→인게임 유입 CPR이 저조한 경우** 있음 → 도입부는 AI 영상으로 시선을 끌고 **본편은 실제 인게임 플레이 영상**으로 전환율 확보
- 크래프톤: **웨스턴 게이머는 창작물의 AI 활용에 민감** → 소재 제작에 AI 미사용, 대신 **기획 단계에 적극 활용**
- 인도네시아 크리에이티브를 **문화 코드에 맞춰 전면 재작업** → 획득 단가 **1/3 수준**으로 감소, 전환율 개선

## HOW — 어디에 선을 그을 것인가
**AI의 한계 3가지 (넥슨 김선희 팀장)**
1. **데이터에 나타나지 않는 맥락을 이해 못 함** — 상시 소재 vs 업데이트 소재 효율 비교를 시키면 "업데이트 소재가 매력 없어서"라고 해석. **실제로는 상시 소재가 장기 라이브되며 매체 최적화가 진행된 맥락**을 AI는 모름
2. **상관관계와 인과관계를 혼동**
3. **AI는 책임을 질 수 없다** — 확률과 시나리오는 제시하지만 실패 시 손실과 조직이 감수할 리스크를 책임지지 못함
   - 실제 사고: 광고 자동 최적화 과정의 사이즈 베리에이션·네이티브 최적화에서 **확률형 아이템 표기가 누락** → 유저 고발, 게임위 손해배상 자료 제출 사례 발생
   - 런칭 게임 플랜·프로젝션은 예측 자료이자 **목표의 성격** — AI가 잡은 수치의 미달을 누가 책임지는가

**역할 구분 (게임사 실장)**
- AI = **초안 작성자이자 서포터** (데이터 수집·가공·분석, 메시지 콘셉트·스토리보드 초안, 보고서 초안)
- 사람 = **방향 설정·최종 기획·퀄리티 검수·최종 보고서**
- 현 단계는 **AI에게 우리 게임의 마케팅 운영 가이드와 지표 판단 기준을 학습시키는 단계**

**게임 산업의 역설** — 데이터가 많아 **AI 적용 장벽은 낮지만 해석 난이도는 매우 높음**
- 단발성 구매가 아니라 **장기 LTV·코호트** 관점으로 판단해야 함
- **고래 유저 같은 아웃라이어**가 전체 지표를 크게 왜곡
- 태생부터 퍼포먼스 마케팅과 함께한 산업이라 **프로드(과집계·오집계) 위험**이 높음

## HOW — 정착의 장벽과 극복
> "가장 큰 어려움은 **성급한 포기와 습관적으로 돌아가는 관성**이었습니다."
- AI 결과물을 보고 "생각보다 별로네, 아직 쓸 만하지 않네" 하고 기존 방식으로 회귀
- 눈높이에 맞추려면 **프롬프트를 반복 수정·튜닝하는 피드백 루프**를 견디는 인내심 필요
- 극복 방법: **작은 업무부터 시작해 성공 경험을 만드는 것**. 알케론 모니터링 툴도 처음엔 기능이 단순하고 버그가 많았지만 담당자가 보완해 지금은 잘 활용
- **시행착오 기간을 기다려주고 응원하는 조직 문화**가 필요

## CASE — 마케터가 직접 만든 도구
- 알케론 CBT: 일본 인플루언서 동향 파악이 언어 장벽으로 어려웠음
- **실 소속 마케터가 Claude로 모니터링 툴을 직접 제작** → 트위치·유튜브 라이브 방송 수, 동시 시청자 수, **페이드/오가닉 인플루언서 구분**, 방송 내용·채팅 반응을 **한국어 요약 리포트**로 확인
> "솔루션을 사는 대신 필요한 사람이 직접 도구를 만들었다. **도구를 사는 시대에서 만드는 시대로**"

- 크래프톤 중국 시장 리서치 자동화: 바이두·중국 게임 전문 매체에서 **매일 800~900건** 수집 → **딥시크 API**로 이슈 묶고 사업·판호·마케팅 관점으로 선별 → **하루 70~80건**만 남겨 **아침마다 전사 메신저·위키로 발행**. 텍스트만 보내면 안 읽히므로 **이미지 카드도 함께**, 상세 리포트는 Confluence에 축적

## HOW — 모르는 시장을 판단하는 3단 필터 (크래프톤)
1. **아는 시장으로 보정** — 인도네시아를 묻기 전에 **같은 질문을 한국 게임 시장에 던져** 내 이해와 얼마나 맞는지 확인 → 모델별 신뢰 수준 감 잡기
2. **교차** — 여러 LLM에 동일 질문. 모델마다 참조 소스가 다름. **겹치는 답을 우선 참고**
3. **반론** — "A 모델은 이렇게 답했는데 너는 어떻게 생각해?" 로 서로 반박시켜 **끝까지 살아남는 결론** 도출
+ 로컬 팀을 통한 백체크·크로스체크는 반드시 병행

**문화 코드 예시** — 인도네시아: 보상·성취 강조 + **마바르(함께 플레이) 문화** → 협동 강조 / 태국: 경쟁 강도가 높으면 피로도 급상승, **애국심 높은 권역** → 드라마타이징 감정선 / 신흥국 공통: 저사양 기기 우려 → **"저사양에서도 잘 돌아간다"는 디스클레이머 필수**

## POV — 사라질 역량 vs 중요해질 역량
| 사라질 것 | 중요해질 것 |
|---|---|
| 엑셀 수식, 데이터 정확·신속 집계 | **의사결정의 설계력** — 어떤 데이터를 신뢰할지, 어떤 KPI로 판단할지, 어떤 리스크를 감당할지 |
| 메시지 세팅·미디어 조절·리포트 작성 등 **데이터 전달자 역할** | **AI를 디렉팅하는 능력** + 매체·유저 맥락 파악. "메타 피드/릴스/스팀에서 초반 3초가 어떻게 다른지" 해석 |
| — | **구조 설계화 역량** = ① 문제를 고르는 눈(산업·직무·회사 3필러에서 시급도↑·임팩트↑·구현가능) ② **스스로의 기준** ③ **조직을 얻는 힘** |

> **"저희 같은 실무자들이 만든 AI 제품들은 결국 참가자 본인의 실력과 수준을 넘기 어렵습니다. 제가 만든 자동화 리포트의 수준은 결국 제가 알고 있는 UA의 세계관을 뛰어넘기 어려운 것이죠."**
> **"혼자 쓰면 개인기로 끝나고, 남이 쓰기 시작해야 본격적으로 시스템이 됩니다. 아무리 좋은 제품을 만들어도 옆자리 동료나 조직이 거부하면 끝입니다."**

## 멋사 적용 포인트
- **가장 정직한 세션. 이 카드는 "AI 도입 낙관론"에 대한 균형추로 반드시 브리핑에 포함할 것**
- **리포팅 60시간 → 5시간**은 우리 주간/월간 모집 리포팅에 그대로 대입 가능한 목표치
- **"AI는 책임질 수 없다"** — 정부지원 사업(KDT)은 **규정 준수 리스크가 게임의 확률형 아이템 표기와 유사**. 훈련비·수료 요건·모집 문구는 **AI 자동 생성 금지 영역**으로 명시할 필요
- **AI 사용 영역 구분표를 즉시 만들 것** — 넥슨 방식: 논IP 게임은 AI 소재 OK, 연예인 IP·스팀은 금지. 우리 버전: **일반 홍보 소재 OK / 정부지원 고지·수료생 실명 콘텐츠·취업 실적은 AI 생성 금지**
- **3단 필터(보정·교차·반론)** 는 신규 시장·신규 과정 리서치에 그대로 적용
- **"조직을 얻는 힘"** — 개인이 만든 자동화가 조직 시스템이 되려면 옆자리 동료의 문제를 같이 푸는 것까지 해야 함 (D1-5 "설득자"와 동일 결론)
- **정착 장벽 = 성급한 포기와 관성** — 도입 초기 시행착오를 기다려주는 조직 문화를 리더가 명시적으로 선언해야 함

# [3F-5] '약'으로 뷰티를 해결하는 시대: 트러블 시장을 바꾼 새로운 공식

## 한 줄 요지
경쟁사 점유율을 뺏는 스위칭이 아니라 **소비자의 숨은 니즈를 카테고리로 전환해 시장 자체를 새로 만든다.**

## FACT
- 노스카나 시장점유율 **90% 이상**
- 여드름 치료제 시장 원래 규모: **6개 브랜드, 약 35억 원** → 노스카나 출시 후 세분화하며 파이 확대
- 에크논 등 세분화 제품군으로 MS **66%** 확보
- 성수·홍대·명동에 **약국이 하나 건너 하나** 생겨나는 중 — 과거 화장품샵·옷가게 자리
- 관광객이 **약국을 쓸어가는** 현상 (미국·중국·대만·홍콩)

## HOW — ① 인식 전환으로 카테고리 창출 (노스카나)
**전통적 제약 광고 공식**: 증상 → 솔루션 (감기엔 판피린, 소화엔 베나치오, 잇몸엔 이가탄)
**노스카나가 바꾼 것**: 여드름을 **가라앉히는 약**에서 → **여드름의 흔적·흉터를 케어하는 아이템**으로
- 즉, **증상 완화를 넘어 "뷰티" 개념까지 확장**
- 메시지 진화: **"여드름 그냥 두면 안 돼, 흉지니까 케어해야 돼"** → **"흉지면 약도 없다, 흉터엔 바르는 게 약이다"**
- 결과: 40~50대가 가던 올드한 약국이 **10대·20대가 가는 약국템**의 공간으로 전환

## HOW — ② 전문화·세분화로 파이 키우기
할로 이펙트를 활용해 여드름 시장을 잘게 쪼갬
- 여드름 치료 **후** 좁쌀 여드름 / 화농성 붉은 여드름 / **압출 후** 상처용 연고 / 몸드름·등드름
- 각 증상별 제품을 신규 출시 → **증상별 솔루션 가이드**로 커뮤니케이션
- 에크논: 코로나 시기 **"마스크 속 뾰루지"** 라는 시의적 소구로 진입 + **피부 전문 인플루언서와 코업 콘텐츠 개발** → **반응 좋은 콘텐츠를 광고로 재편집해 미디어 집행**

## HOW — ③ 시장 재정의 + 타깃 세분화 (멜라토닌)
- 기존 인식: 색소침착 크림 = **기미·주근깨 = 50대 엄마들**이 사는 것
- 재정의: **"기미·주근깨"라는 올드한 단어 대신 "색소침착"이라는 키워드를 새로 만듦**
- 컨셉 전환: 생기고 난 뒤 바르는 게 아니라 **사전 케어·사전 예방, 아주 옅은 색소침착도 미리미리**
- 타깃: **30~40대 여성**
- **중간 포지셔닝 전략**: 피부과(비싸다) vs 화장품(효과 약하다) 사이 → **"화장품보다 효과적이고 피부과보다 가성비 좋은" 대체재**
- 모델 전략 학습: 처음엔 노스카나와 같은 모델로 할로 이펙트를 노렸으나 **브랜드 혼동 발생** → 별도 모델로 전환 → 올해 전지현 기용

## HOW — ④ 이탈 방지 장치
- **약은 온라인에서 구매 불가** → 유사 컨셉·유사 제품명의 화장품과 싸워야 함
- 광고에 명시적 장치: **"멜라토닌은 검색으로 못 사요. 약국에만 있어요."**, "캡처해서 약사님께 보여주세요"
- 글로벌 클레임 대응: 중국에서 히트 후 **사용법을 안 읽고 얼굴 전체에 도포**하는 사례 발생 → **다국어 사용설명서 + 약국용 다국어 POP/POSM** 제작

## POV
- 전략의 본질은 **스위칭이 아니라 파이 확대** — "화장품 시장, 피부과 시장이라는 더 큰 잠재 시장에서 가져오는 것"
- 제약 광고는 예쁘거나 트렌디할 필요가 없다. **"언제·어떻게·왜 써야 하고, 내 증상에 어떻게 써야 하는지"** 가 핵심
- 마케팅은 더 이상 국내만 커버하지 않는다 — **콘텐츠가 쌓여 글로벌로 확산되고 다시 한국으로 오게 만든다**
- 미디어 믹스 전환: **TVC는 서브**, 디지털 중심 + **메가급·마이크로급 인플루언서 믹스** + 검색 대응 + 사용법 후기

## 🔁 교차검증 강도 3

## 멋사 적용 포인트
- **가장 강력한 이식 대상: "시장 재정의"** — 우리는 "국비지원 부트캠프"라는 레드오션에서 점유율을 다투는가, 아니면 **새 카테고리를 정의**하는가?
  - 노스카나 방식 대입: "취업 준비"가 아니라 **"커리어 전환 후 정착"**, "코딩 교육"이 아니라 **"AI 시대 직무 재설계"** 처럼 **아직 이름 없는 니즈에 이름을 붙이기**
  - ⚡ **3F-8 웍스피어의 "기준이 없는 영역에 우리가 먼저 기준을 제시한다"와 정확히 같은 논리** → AEO/GEO에서도 그대로 작동
- **KDC 세분화 전략** — 노스카나가 여드름을 좁쌀/화농성/압출후/몸드름으로 쪼개 파이를 키웠듯, **"백엔드 개발"을 목적·상황별로 세분화**(직무 전환용 / 재직자 심화 / 사이드 프로젝트용)해 시장을 키우는 접근
- **CTS** — 인플루언서 코업 콘텐츠 중 **반응 좋은 것을 광고 소재로 재편집**하는 방식은 3F-1(Google)과 동일. 즉시 실행 가능
- **중간 포지셔닝 전략** — 대학(비싸고 길다) vs 독학/유튜브(싸지만 효과 약하다) 사이에서 **멋사의 "애매한 포지션"을 역이용**하는 메시지 프레임
- 🔵 약국 한정 판매 규제 대응은 비적용

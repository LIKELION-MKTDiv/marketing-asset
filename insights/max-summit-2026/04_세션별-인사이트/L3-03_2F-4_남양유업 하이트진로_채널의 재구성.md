## 한 줄 요지
**같은 기준에서 정반대의 선택.** 채널 전략은 "어디서 팔 것인가"가 아니라 **"각 채널이 어떤 역할을 맡을 것인가"** 의 문제다.

## FACT
### 하이트진로음료 — 자사몰(진로토닉몰) 강화
- 2026 상반기 GMV **전년 동기 대비 +107%** (2배 이상)
- 최근 90일 **매출의 60%가 재구매 고객**에서 발생
- 재구매 고객 객단가가 신규 고객보다 **약 30% 높음**
- 최근 **월 단위 손익분기점 돌파** 시점 발생
- **1인 담당 체제**로 자사몰 운영·CRM·온라인 광고·데이터 분석 총괄

### 남양유업 — 오픈마켓(네이버·쿠팡) 중심 전환
- 별도 유입 광고·CPA 광고 없이 검색량·신규 고객·재구매 고객 증가
- 매출 **전년 대비 +75% 이상**, 2026년 **매달 역대 최고 매출 경신**
- 2년 전 같은 무대에서 "자사몰로 브랜드 성장" 주제로 발표했던 연사가 정반대 전략을 발표 — **"조금 아이러니하긴 합니다"**

## HOW — 판단 기준의 분기
| | 자사몰 (하이트진로) | 오픈마켓 (남양유업) |
|---|---|---|
| 판단 기준 | **캠페인·사업의 목적** | **고객이 어디서 가장 자연스럽게 구매하는가** |
| 논리 | 회원 확보·재구매·상품 구성/CRM/신규 서비스 **직접 실험**이 목적이면 자사몰 | 식품은 구매 여정이 **이미 플랫폼 중심**으로 형성 → 고객을 플랫폼 밖으로 빼내기보다 **고객이 있는 곳에서 경험을 개선** |
| 얻는 것 | 고객 데이터 / 실험 권한 / 플랫폼 의존도 완화 / **내부 학습** | 검색 편의·빠른 배송·익숙한 결제 경험 |
| 비용 | 지속 유입에 **상당한 마케팅 비용 + CRM 역량** 필요 | 데이터 분석 한계 (구조 설계 어려움) |

**채널별 역할 분리 (하이트진로)**
- 오픈마켓(쿠팡) = 대규모 브랜드 광고 시 **랜딩 채널** (회원가입·복잡한 탐색 없이 즉시 구매)
- 자사몰 = 회원 확보·재구매·데이터 축적·**게이미피케이션 등 자사몰에서만 가능한 경험**

**채널별 역할 분리 (남양유업)**
- **네이버** = 검색에서 시작 → 비교·정보·리뷰 → 브랜드 노출, 라이브커머스, 기획전으로 **브랜드 경험** 설계
- **쿠팡** = 생활 속 구매 → 로켓배송 → **반복 구매와 편의성**
> "같은 제품이라도 채널이 달라지면 고객의 기대도 달라집니다."

**AI·데이터 활용 3건 (하이트진로)**
1. **배송 개선** — 반복 VOC를 AI로 1차 분류 → 평일·주말 모두 **이틀 도착** 빠른 배송 도입
2. **상세페이지 개선** — 리뷰 **약 9,000건**을 구매 이유·사용 상황·반복 구매·선택 혼선으로 분류 → 비교표·선택 가이드·FAQ 개선
3. **탐색 구조 개편** — 이탈 지점 확인 후 기획전 탐색 구조 개편 → 기획전→상세 이동률 **29.8% → 30.8%**

## POV
- **"채널 정비는 판매처를 줄이는 작업이 아니라, 각 채널에서 무엇을 얻고 어떤 리스크를 나눌지 정하는 과정입니다."**
- **"온라인 채널을 많이 운영하는 시대가 아니라 잘 운영하는 시대"**
- 모든 채널에서 같은 상품·가격·프로모션을 운영하면 → 채널 간 가격 경쟁 심화 + **특정 플랫폼 의존도 상승** → 플랫폼 정책 변경 시 브랜드 전체가 흔들림
- 평가 기준: 단순 매출이 아니라 **지속 가능한 성장** — 고객이 스스로 찾아오고 다시 구매하는 구조

## 멋사 적용 포인트
- **가장 중요한 교훈: "정답 없음, 목적별 역할 분리"** — 자사 채널(홈페이지·자체 커뮤니티) vs 외부 플랫폼(네이버·유튜브·잡플래닛·커리어 커뮤니티) 중 무엇이 옳으냐가 아니라 **각각 무엇을 얻을 것인가**
- **KDT/KDC 채널 역할 재정의 초안**
  - 외부 플랫폼(검색·SNS·커뮤니티) = **신규 관심 확보 + 즉시 지원 전환**
  - 자사 채널 = **회원 데이터 축적 + CRM + 신규 과정 테스트 + 수료생 관계**
- **리뷰 9,000건 AI 분류 → 상세페이지 개선**은 즉시 이식 가능: 우리의 **수료 후기·상담 문의·설명회 Q&A**를 AI로 분류해 **비교표·선택 가이드·FAQ**로 재구성 (이는 3F-6 AEO 실행과도 정확히 겹침)
- **재구매 = 재수강/추가 과정** 으로 치환: 재수강 고객의 객단가·기여 비중을 지금 측정하고 있는가?
- ⚠️ 1인 담당 체제로 자사몰을 2배 성장시킨 사례는 **리소스 제약 하 운영 벤치마크**로 유효

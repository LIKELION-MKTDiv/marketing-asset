## 한 줄 요지
GEO는 막연한 개념이 아니라 **숫자로 관리할 수 있는 영역**이며, 그 시작은 지금 우리 위치를 정확히 측정하는 것이다.

## FACT
- ChatGPT가 **전 세계 웹사이트 트래픽 순위 6위** 진입
- 한국 시장 Top5 AI 챗봇 사용량: 2024년 5월 이후 **6개월마다 2배 이상 증가**. 같은 기간 검색 엔진은 정체 또는 **3% 감소**
- ChatGPT 리퍼럴 트래픽의 **전환율이 기존 마케팅 채널보다 높음** — 특히 **호텔·교육·법률서비스** 등 구매 전 비교 검토가 많은 업계
- 대화형이라 **체류 시간이 자연히 길어짐**
- 사람들은 **1.7초 만에** 보던 콘텐츠를 바꿈. 매출이 늘어도 마케팅 예산은 줄이는 추세

## HOW — SEO vs LLMO
| | SEO | LLMO/GEO |
|---|---|---|
| 대상 | 네이버·구글 검색 엔진 | 답변을 생성하는 AI 환경 |
| 목적 | 검색 순위 상승 | **AI 답변에 언급되기** |
| 평가 기준 | 유입 수·순위 | **AI 노출·인용 빈도** |
| 실행 | 키워드 세팅, 백링크 | 질문 의도에 직접 답하는 구조, AI가 요약하기 좋은 포맷 |

**LLMO 3대 기준** ① 검색 적합성(질문 의도에 직접 답하는가) ② 답변 구조(스펙·장단점·특징·가격을 AI가 이해하기 쉬운 문맥으로) ③ **비교 테이블에 우리 이름이 올라가는가**

### 현장 퀴즈 2개 (그대로 옮겨 쓸 수 있는 교육 자료)
- **퀴즈1** — A) 블로그 후기형 콘텐츠 vs B) 세련된 브랜드 매거진 → **정답 A.** AI는 디자인이 좋은 페이지가 아니라 **질문에 직접 답할 수 있는 정보 밀도**를 우선함
- **퀴즈2** — A) 특수문자 섞인 URL vs B) 의미가 읽히는 URL → **정답 B.** 정리 안 된 주소는 **신뢰하지 않고 아예 읽지도 않음.** 한국 기업 사이트 상당수가 A 상태

## CASE
- 보험사 A: SEO 키워드 위주 콘텐츠를 **AI가 좋아하는 질문 구조로 재설계** → AI 인용 **269.5% 증가**
- 부동산 B: AI가 읽지 못하던 **사진 위주 콘텐츠**가 원인임을 진단 → 최적화 성공
- 운동화 N사: "러닝화 온라인 구매가 불안한데" 프롬프트에서 Gemini가 **55% 확률로 N사 언급**. 동시에 "불편하다"는 부정 답변 확인 → 제품 개발 인사이트 도출
- **120일 로드맵**: 1개월 기술 수정(URL·브랜드 명칭 정리) → 2개월 차부터 양질 콘텐츠 + 외부 평판 → 90~120일에 가시성 상승

## GEO 12개월 KPI 예시 (그대로 벤치마크 가능)
| 축 | 지표 | 현재 → 목표 |
|---|---|---|
| 가시성 | 브랜드명 없는 일반 질문 언급률 | 7.4% → **25%** |
| 가시성 | 브랜드명 질문 언급률 | 78% → **86%** |
| 인용 | 일반 질문 콘텐츠 인용률 | 3.2% → **8%** |
| 인용 | 브랜드 질문 인용률 | 82.1% → **96%** |
| 감성 | 긍정 답변 비율 | 45% → **60%** |
| 감성 | 부정 답변 비율 | 12% → **8% 미만** |

## POV
- 3방향 동시 실행 필수: **① 온사이트(FAQ·깊이 있는 콘텐츠) ② 기술 구조 정리 ③ 외부 평판(뉴스·커뮤니티)** — 셋 중 하나라도 빠지면 효과 반감
- **"AI가 우리 브랜드를 모르면 손해가 아니라 기회 상실"**
- 감으로 콘텐츠만 내리면 120일이 아니라 1년이 걸려도 곡선이 안 나옴 — **정확한 진단에서 출발**해야 함

## 멋사 적용 포인트
- **교육 카테고리가 명시적으로 언급됨** — "구매 전 비교 검토가 많은 업계(호텔·교육·법률)에서 ChatGPT 전환율 향상이 두드러짐". KDT/KDC와 정확히 일치
- **OM** — 위 12개월 KPI 표를 그대로 멋사 버전으로 치환해 **GEO 목표 수립** 가능 (브랜드명 없는 질문 언급률이 핵심 지표)
- **CTS** — 감성 축(긍정/부정 답변 비율) 모니터링은 리스크 관리 관점에서도 유효. "멋쟁이사자처럼 후기" 류 질문의 AI 답변 톤을 정기 점검
- ⚠️ 수치는 벤더 자체 데이터 — 내부 목표 설정 시 **참고값으로만** 사용

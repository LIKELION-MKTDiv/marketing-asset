# [D1-6] AI시대, 고객 경험은 어떻게 진화하는가

**메타** 2026-08-03 16:11 | Day1 | Appier | 27분
**원 도메인** CDP·CRM 솔루션
**L축** L3 전환·커머스
**적용 라인** CRM · CX · CSM
**게이트** 🟡 변형적용

## 한 줄 요지
고객 경로가 **선형에서 비선형·압축형**으로 바뀌면서, CRM 마케터에게 데이터 관리가 오히려 더 어려워졌다.

## FACT
- 매킨지: 버티컬별로 **50% 이상**이 AI 검색을 통해 무언가를 탐색. **전자제품이 가장 높음** (객단가 높고 체험·스토리라인이 얽힌 카테고리)
- 이어서 푸드 → 트래블 에이전시 → 건강식품 → 뷰티 순. 금융 상품은 아직 오프라인 편중
- 시니어·베이비부머도 **70%가 AI를 매일 경험** — 세대별 전략이 아니라 **전 세대 대응** 필요
- 에이전트 AI 활용률 **2030년 최대 20%** 전망 (2026년은 개화기)
- BCG: 에이전트 AI 도입 시 리테일 **매출 15~25% 증가**, 업무 시간 **최대 40% 감소**, **LTV 20% 향상**
- 구매 소요 시간: 선형 검색 기반 **7~14일** → 앞으로 **1~3일**로 단축 전망
- 프로토콜 확장: Google GGP / Anthropic MCP / OpenAI ACP

## HOW — 하이브리드 경로의 등장
**과거** 구글 검색 → 브랜드몰 → 회원가입 → 장바구니 → 결제 (브랜드가 전 과정 장악)
**현재** **프롬프트에서 AI와 대화** → 브랜드몰 이동 → 회원가입·리뷰 확인 → 결제
> 경로가 파편화되고 브랜드는 **단지 터치포인트 하나**로 활용됨 → CRM 데이터 관리가 더 어려워짐

- 소비자는 AI에게 **제품만이 아니라 컨텍스트와 스토리를 구매**한다 (목적지·일정·동행자를 프롬프트에 넣는 순간)
- 네이버 스마트스토어 AI 에이전트, 하나투어 CS 상품 내 AI 에이전트 등 **판매형 에이전트 고급화** 가속
- 트래킹 데이터 관리가 핵심 과제 — **AI가 어떤 결과를 던질지 예상 불가**

## CASE
| 사례 | 성과 |
|---|---|
| 국내 대형 뷰티사 | 첫 구매 여정 이탈 개선 — 14일 이내 프로모션 단계 메시지 + 1:1 오프라인 컨설팅 캠페인 → 첫 구매 전환율 **약 2.4배**, 피부톤 맞춤 프로모션 **약 3.1배** ※ 녹취상 "24배/31배"로 표기되어 있으나 **2.4배/3.1배로 해석**하는 것이 합리적 — 인용 시 검증 필요 |
| 동일 뷰티사 업셀 | 세럼 재구매율이 낮은 점을 활용해 **세럼→로션 업셀 오디언스 세그먼트** 별도 추출 → 구매 전환율 최대 3.4% 증가 |
| 해외 패션 가방 브랜드 | 온라인 공식몰·오프라인 POS·회원/상품 데이터의 **사일로 통합(7주)** → 고객 전환 6.6%, **매출액 141%**, VIP 재구매 금액 17%, 세그먼트 효율 2배 |

## POV
- **리테일의 핵심 경쟁력은 데이터** — CDP 없이는 세그멘테이션 고도화 불가
- 오프라인은 사라지지 않음 — 고객 반응을 직접 읽고, 목소리로 브랜드 가치를 전파하고, 점원이 만드는 신뢰는 유지됨. **그 데이터를 쌓으면 AI가 또 다른 인사이트를 준다**
- 역할 분담: **AI = 니즈 분석·구매 의도 파악·가격/효용 비교·최적 옵션 추천 / 브랜드 = 사람과 감성**
- CS 에이전트를 **세일즈 에이전트**로 재정의 — 감정 소모 없이 불만을 달래면서 업셀·크로스셀 기회 발굴
- 마케터는 이제 **브랜드 경험과 고객 경험 설계에 집중**할 것

## 멋사 적용 포인트
- **하이브리드 경로 = 우리 지원자의 실제 경로**: ChatGPT에 "비전공자 부트캠프 추천" → 멋사 사이트 방문 → 후기 확인 → 지원. **유입 경로 트래킹이 안 되는 구간이 앞단에 생겼다**는 뜻
- **CRM/CSM** — "첫 구매 여정 이탈"을 **"지원서 작성~등록 사이 이탈"** 로 치환. 14일 이내 단계별 메시지 + 1:1 상담 조합은 그대로 이식 가능
- **CX** — 데이터 사일로 통합이 핵심 병목. 우리도 **광고 데이터 / 지원서 데이터 / LMS 학습 데이터 / 취업 결과 데이터**가 분리돼 있다면 동일 문제
- **세그먼트 기반 업셀** — 수료생 대상 **다음 과정 추천**(KDT 수료 → KDC 심화, 또는 취업 후 재교육)의 세그먼트 설계에 적용
- ⚠️ 벤더 자료 수치이며 전사 표기 오류 가능성 존재 → **외부 공유 시 수치 재확인 필수**

## 핵심 인용
> "이제 소비자들은 AI에게 단순하게 제품만 구매하는 게 아니라 컨텍스트와 스토리를 구매하게 됩니다."
> "경로가 파편화되고 브랜드가 단지 터치 포인트에서 활용되고 있기 때문에 CRM에 대한 관리가 더욱더 어려워지고 있습니다."

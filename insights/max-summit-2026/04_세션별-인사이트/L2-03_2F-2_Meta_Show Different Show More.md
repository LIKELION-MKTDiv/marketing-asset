## 한 줄 요지
**크리에이티브 다각화가 새로운 타겟팅이다** (Creative Diversification is the New Targeting).

## FACT
- Meta 광고 매출의 **약 90%가 전환 목표 캠페인**에서 발생
- 백엔드 3단 구조: **안드로메다**(광고 후보군 추림) → **Meta Gem**(노출 순서 결정) → **Meta Lattice**(과거 히스토리 학습해 우선순위 최적화)
- 뷰티 광고주 중에는 **전체 캠페인 예산의 50%까지 파트너십 광고**로 운영하는 경우 있음
- **PC 지면은 여전히 유효** — "요즘 누가 PC로 보나" 통념과 달리 예산만 적절히 분배되면 문제없음

## HOW — 옛 방식 vs 지금
**옛날 함정** — 여성 18-34로 광고세트 5개를 나누고 관심사(음식/여행/뷰티/피트니스/음악)를 각각 넣음
> **"그런데 여성 18-34는 음식·여행·뷰티·피트니스·음악을 다 좋아합니다."** → 사실상 광고세트 1개와 동일

**지금** — A+ SC 캠페인이 오디언스·플레이스먼트·데스티네이션·예산을 자동 적용. "레고처럼 하나씩 조립"에서 **"만들어서 주고, 뺄 것만 빼세요"** 로 전환
→ **방점이 크리에이티브로 이동**

**핵심 문제 제기** — 마케터 눈에는 5개의 다른 소재지만, 피드를 넘기는 유저 눈에는 "회색 바탕에 노란색 상품" 하나다.
- 유사 소재 → 특정 소구점에 반응하는 유저에게만 반복 노출 → **피로도 증가**
- 그 외 소구점에 반응할 유저를 놓치는 **기회비용** 발생
- 진단법: 광고세트 세팅 시 **예상 도달량 500만인데 실제 50만**이면 이 현상일 가능성 높음

## CASE — 오버드(운동기구)
- 상위 노출 크리에이티브 Top10을 뽑아보니 전부 **"여성 + 다이어트"** 연상
- 그런데 SKU가 하나뿐 → 한 번 사면 재구매 없음 → **오디언스 확장이 필수 미션**
- 페르소나 재설계: 1인 가구(싱글·독방 공부족·**남성**) / 4인 가구(홈트·인테리어·안마의자·유도)
- 인플루언서 협업 크리에이티브 제작 → **가장 반응 좋았던 조합은 "공부 + 남성"** (전혀 예상 못 한 오디언스)
- 부가 인사이트: 제품에 의도적으로 손잡이가 없는데(코어 운동 목적) **공부하는 사람은 잡을 것이 필요** → 액세서리 구성 아이디어 도출

## 크리에이티브 중심 퍼널 4종 상품
| 상품 | 용도 |
|---|---|
| **M3 (Meta Moment Maker)** | 타깃 오디언스의 **40~60%에게 짧은 기간 폭발적 노출**. 경매형이 아닌 **예약형** → 예산 사전 확정 |
| **Reels 트렌딩 광고** (베타) | 인기 릴스 콘텐츠 **직후에 배치** |
| **알림 광고(Reminder Ads)** | 클릭해두면 **3회 리마인드**. 신제품 출시·사전예약에 최적. **브랜딩→퍼포먼스 브리지** 역할 |
| **라이브 비디오 광고** | 오가닉 라이브를 증폭 + CTA 버튼으로 즉시 구매 연결 |

**제품 표시(카탈로그)** — 단일 영상/이미지 하단에 카탈로그 상품을 다이내믹하게 붙여 크로스셀. **비주력 SKU에 노출 기회** 부여

## CASE — 디어달리아 립 3종 / 말해보카
- 디어달리아: M3(배우) → Reels 트렌딩(인플루언서 소재) → **알림 광고(출시 전 예고)** → 출시 후 협력광고·파트너십 광고 → 직원 라이브 → 라이브 중 반응 좋은 구간을 다시 광고 소재화
- 말해보카: 모델 브랜딩 소재를 **ThruPlay 최적화**(끝까지 볼 사람에게 노출) → 유튜브 콘텐츠를 편집해 인스타/페북 소재로 전용 → 파트너십 광고. **한국·대만 앱스토어 1위**
- 해외 진출 시 최대 난제는 크리에이티브 → **현지 로컬 크리에이터 협업**이 해법

## POV
> **"공을 쫓아가지 말고 사람을 쫓아가라."** 결국 우리는 유저를 찾아가기 위해 광고한다.
- 무기 하나를 쥐어주면 모든 문제를 그 무기로 해결하려 한다 → **연장통에 다양한 연장**을 갖춰야 함

## 멋사 적용 포인트
- **KDT/KDC 최우선 적용** — 지금 우리 모집 소재도 "20대 취준생" 하나의 얼굴만 반복하고 있지 않은가? 오버드 사례를 그대로 대입: **직무전환 30대 / 육아 후 복귀 / 재직자 업스킬 / 지방 거주자 / 비전공 문과생** 별 크리에이티브 축 분리
- **예상 도달량 대비 실제 도달량 갭 점검**을 이번 분기 모집 캠페인에 즉시 적용 → 소재 동질화 진단
- **알림 광고** = KDT 모집 오픈 **사전 알림**에 정확히 맞는 상품. 기수제 모집과 궁합 최상
- **CTS** — "반응 좋았던 라이브 구간을 광고 소재로 재활용"은 설명회·OT 라이브에 그대로 적용 가능

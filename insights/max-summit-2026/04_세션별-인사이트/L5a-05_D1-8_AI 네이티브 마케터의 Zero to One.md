# [D1-8] AI 네이티브 마케터의 Zero to One: 아이디어가 떠오른 순간부터 고객에게 전달하기까지

**메타** 2026-08-03 17:29 | Day1 마지막 세션 | (아티스트 IP 기반 콘텐츠 기획·신사업 발굴) | 41분
**원 도메인** 엔터·IP
**L축** L5a 조직·거버넌스
**적용 라인** 전사 · CTS · OM
**게이트** 🟢 직접적용 — **실무 재현성이 가장 높은 세션**

## 한 줄 요지
AI로 바꾸고 싶은 건 속도가 아니라 **주도권**이다. 마케터가 기능 조직 의존성 없이 하루 만에 기획→릴리즈까지.

## 문제 정의
마케팅 업무 흐름: 아이디어 → 협의 → 플래닝 → **디자인 전달** → **개발 이관** → 테스트 → 도메인 연결 → 릴리즈 (가벼운 랜딩도 **2~4주**)
- 1차 병목: 디자이너와의 커뮤니케이션
- 2차 병목: 개발
- 릴리즈 후에도 A/B 테스트로 카피·CTA 수정하려면 **다시 같은 구간을 돈다**
> **"업무의 병목이 아이디어 자체가 아니라 기능 조직에 대한 의존성에서 발생한다."**

## POV — 마법과 상상
> 애니메이션 『장송의 프리렌』의 세계관: **마법은 상상의 세계다. 상상할 수 없는 건 마법으로 실현할 수 없다.** 그게 유능한 마법사와 무능한 마법사의 차이.
> AI 기능 아이콘이 다 마법봉 표시인 이유가 있다. **AI는 마법봉 같아 보이지만 상상은 사람이 해야 한다.** 그 상상을 좁히면 **가설**이다. "AI로 해결하고 싶은 문제가 뭐고, 너의 가설은 뭐야."

## HOW — ① 개인 지침(Global) 설정
사용 도구: Claude · Manus · Pixverse

**전역 지침에 넣은 것들**
- **"요청은 서머리 40자로 해줘"** — 사람에게 말하듯 하면 생략되는 컨텍스트가 많고 한국어 뉘앙스 탓에 프롬프트가 제대로 도달했는지 확인이 어려움 → **AI가 먼저 "너 이 얘기하는 거지"라고 요청을 정리**해 주게 함
- **"권고안 하나만 내지 말고 대안 2개를 프로스/콘스와 함께"** — 실제로 대안1이 더 좋을 때가 있음. **더 좋은 아이디어일 수도, 내가 컨텍스트를 충분히 전달하지 못했을 수도**
- **"피드백은 칭찬 없이 개선점 위주로, 논리에서 빠진 부분을 적극적으로 지적하고 동조하지 말 것"**
- **"모르는 건 모른다고, 확인 필요라고 표시"** — 할루시네이션이 있어도 그 부분만 중점 검증 가능
- **"슬라이드/PDF를 바로 만들지 말고 마크다운 텍스트로 헤드라인·바디·이미지 영역·레이어를 먼저"** — 토큰 절약
- **"달러는 현재 환율 적용해 원화 병기"** — 가독성

## HOW — ② 프로젝트(Local) 분리
- 매번 같은 맥락을 설명하는 낭비 제거, 해당 프로젝트에서만 기억할 콘텐츠 분리
- **사업계획서 쓰다가 슬라이드 미팅으로 톤이 깎이는 문제** → 프로젝트를 아예 분리
- 결과: 새 대화마다 처음부터 시작하지 않고 **축적된 맥락 위에서 바로 실행**
- Manus에도 **"다른 AI 개인 지침 가져오기"** 기능 존재 (프롬프트 복사 → 다른 툴에 넣고 답변을 가져오면 개인화 설정을 그대로 기억)

## HOW — ③ 하루 만에 기획→릴리즈 (전체 플로우)
1. **비즈니스 모델 캔버스 / 린 캔버스**에 먼저 채워 넣기 → Claude에 전달
   > "저것 없이 내 얘기만 주구장창 하면, AI는 자기가 하고 싶은 얘기·내가 듣고 싶은 얘기만 해 준다."
2. **브랜드 가이드라인** — 컬러는 코드가 아니라 **비율**이 중요. 전체 이미지 톤에서 오렌지가 몇 %인가. **이 지점에 브랜드 디자이너의 역할이 필요**
3. **KPI 정의** — 비즈니스와 수익 구조를 알려줬으니 자연스럽게 도출 가능
4. **와이어프레임을 ASCII 텍스트로 먼저** — 바로 웹페이지로 만들면 시간·토큰 낭비. 히어로 섹션·섹션1·CTA 구조가 텍스트로 빠르게 나옴 → 의도 확인 후 다음 단계
5. **비주얼 확인** — 이미지로 먼저 생성(카피·포맷 매너 확인) → 코드로 구현
   - Claude Code는 이미지 생성 불가 → **Pixverse MCP 연동**으로 Claude에서 제어
   - 원하는 느낌은 말로 설명하기 어려움 → **참고 이미지를 캡처해 넣고 "이 이미지를 ChatGPT에서 생성할 영어 프롬프트를 작성해줘"**
6. **릴리즈** — Manus는 게시 버튼을 누르면 즉시 퍼블리싱. 도메인 버튼으로 **약 20분 만에 원하는 URL 연결**
7. **폼·결제·SEO** — 신청 시 지정 이메일로 자동 발송 / Stripe·토스페이먼츠 연동 가능 / **SEO 스코어를 달아 "Optimize" 를 누를 때마다 점수 상승** (alt 태그 등 자동 보완)
8. **수정 3가지 방법**
   - ① Manus 편집 모드에서 영역 선택 후 "왼쪽 패딩 2배" 식으로 지시 (마케터 단독)
   - ② 개발자 모드에서 셀렉터 복사 → "이 영역을 120% 키워줘" (마케터 단독)
   - ③ **html.to.design 크롬 익스텐션**으로 HTML을 Figma 파일로 변환 → 디자이너에게 최소 리소스로 요청 → 링크 연동해 디자인 교체
9. **어드민 생성** — "어드민 만들어줘" → 고유 URL + DB(가입 회원·이메일 축적) + UTM 소스 + **A/B 테스트 기능**
10. **소셜 확산** — 앞의 캔버스·전략·브랜드 가이드가 이미 있으니 **인스타 피드·스토리 콘텐츠를 같은 프로젝트에서 기획**. 스토리용 레이어로 만든 뒤 잘라 피드용으로. 이미지 2장을 붙여 4초 영상 → 애니메이션 → 음악 삽입해 스토리 업로드

## POV — 역할의 재정의
- **디자이너는 사라지지 않는다.** AI 쓰는 건 그대로 가고, **"AI로 만든 결과물이 AI처럼 보이지 않게 하는 것"** 이 주 역할이 된다. 역할이 바뀔 뿐
- 시간 배분의 변화: 과거 루틴 업무 80% → 지금 20%. **AI 네이티브 조직에서는 프롬프팅 노하우 20%, 나머지는 "이걸 어떻게 진정성 있게 전달할까"** 를 고민하는 룸
- **도메인 지식이 결정적** — "다이어트 효과에 대해 말하는 콘텐츠가 정말 리얼한지 구분할 수 없는데, 그게 정말 맞을까" 같은 고민 시간이 늘어나야 함

## POV — 왜 조직은 안 바뀌는가 (핵심 진단)
- 리더는 의지가 강함 — 8시간 AI 워크샵에 대표들이 옴. **"알아야지 시키지"**
- 실무자도 쓰고 싶어 함 — 집에 빨리 갈 수 있고, 빨리 결과물을 보면 퀄리티를 더 높일 수 있으니
- **그런데 왜 안 되는가: 조직이 기능 단위로 나뉘어 있기 때문**
  - 마케터가 디자인·프론트·백엔드까지 다 할 수 있게 됐는데, 그걸 개발팀에 주면 개발팀 입장에서는 위기
  - 반대로 디자인에서 카피·상위 기획까지 하면, 크리에이티브 브리프를 만든 마케터 입장에서는 "이 사람이 왜 여기까지 하지"
  - **→ 기능 단위 조직 리더들 사이에서 베네핏이 안 온다**
- **해법: 목적 조직(Cross-functional)** — "AI를 활용한 워크샵 활성화"라는 목표를 가진 **문제 해결사들의 모임**. 조직 A는 인게이지먼트·매출, 조직 B는 신규 사용자에게 비즈니스 노출 등 **목적 중심 조직**

## 멋사 적용 포인트
- **전 직원 즉시 적용: Claude 개인 지침 세팅.** 이 세션의 지침 세트를 **멋사 표준 개인 지침 템플릿**으로 배포 가능 (요청 요약 / 대안 2개 + 프로스콘스 / 칭찬 없는 비판 / 모르면 모른다 / MD 먼저, 슬라이드 나중)
- **프로젝트 분리** — 멋사 업무 특성상 KDT / KDC / OM / 기업교육을 **프로젝트로 분리**하면 톤 오염 방지
- **CTS/OM — 랜딩페이지 주도권 확보가 가장 큰 실익.** 기수 모집 랜딩, 설명회 신청 페이지, 이벤트 마이크로사이트를 **디자인·개발 대기 없이 마케터가 직접** 만들고 A/B 테스트까지. 특히 **"임시로 쓰는 마이크로사이트는 오래 갈 필요가 없으니 이 방식이 낫다"** 는 조언이 정확히 맞음
- **"AI가 만든 것처럼 보이지 않게 하는 것이 디자이너의 역할"** — 우리 디자인 인력의 역할 재정의 논의에 그대로 사용
- **⚡ 가장 중요한 진단: 조직이 안 바뀌는 이유는 개인의 의지가 아니라 기능 조직 구조.** 멋사 마케팅 본부가 기능별로 나뉘어 있다면 동일 문제. **목적 조직(스쿼드) 실험**을 소규모로 시작할 근거 (3F-2 올리브영의 트라이브·스쿼드와 동일)
- **"AI 시대에 만들어진 모든 것이 AI로 만들어졌다고 여겨지는 세상에서 나는 어떤 역할을 할 것인가"** — 브리핑 클로징 질문으로 활용

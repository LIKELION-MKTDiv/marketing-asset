## 한 줄 요지
AI는 인지도 높은 브랜드를 인용하는 게 아니라, **질문을 조건으로 쪼갠 뒤 가장 강하게 연결된 브랜드**를 따라간다.

## FACT
- 내년까지 AI 검색이 기존 웹 검색 점유율을 **따라잡거나 넘어설 것**이라는 전망
- 실험: "2박3일 부산 50만 원대 숙소 3곳" → ChatGPT·Gemini·Claude **3개 중 2개가 같은 브랜드(롯데호텔 부산) 추천**
- 2025년 기준 **인터넷상 AI 생성 콘텐츠 비중이 사람 작성 콘텐츠를 추월**
- 트래픽의 **70~80%가 모바일** → 반응형·로딩속도 필수

## HOW — AI의 브랜드 인용 4단계
1. **질문 해석** — 문장이 아니라 조건으로 쪼갬 ("부산" + "50만 원대" + "숙소")
2. **좌표 조합(임베딩)** — 관련 개념 점들을 모아 직조
3. **브랜드 엔티티 검색** — 실제 존재하는 대상으로 식별
4. **답변 생성** — 가장 적합하게 연결된 답안 출력

> **오해 금지:** 인지도가 높거나 검색량이 많다고 무조건 인용되지 않는다.

### 최적화 4항목 × 2영역(자사 웹사이트 / 외부 콘텐츠)
| 항목 | 체크 |
|---|---|
| ① AI가 우리를 아는가 | `robots.txt` 차단 여부, 사이트맵, JS 의존도, 로그인 허들, **통이미지 페이지**, 네이버플레이스·구글비즈니스프로필 등록 |
| ② 정확한 정보를 주는가 | title/description, 정보 계층화, **스키마(JSON-LD)**, 상호·주소·전화번호 **표기 일관성** |
| ③ 어떤 맥락으로 쓰이는가 | 쿼리 팬아웃(하위 질문) 대응 콘텐츠 |
| ④ 신뢰할 수 있는가 | 직접 경험, PR·전문가 인용, **채널 간 메시지 일관성** |

### 인용되는 콘텐츠 3원칙
1. **주관식이 아니라 정답식으로 서두를 쓴다** — AI는 서두 2~3문장에서 답을 가장 많이 뽑음. "안녕하세요, 블로거입니다…" 로 시작하면 사실상 탈락
2. **검증 가능한 팩트는 수치로** — "안전하다"가 아니라 "붓기 2~4일 소요"
3. **비교 가능한 표 구조** — 선택 기준·체크포인트를 도표로 정리하면 AI가 그대로 옮겨감

## CASE
- 다이어트 클리닉 블로그: 서두를 **"○○병원은 체중 감량이 아니라 특정 부위 라인을 조절하는 시술입니다"** 라는 정의문으로 교체
- 유튜브 활용: 하위 질문에 원장이 직접 답하는 영상 → **제목·자막 텍스트까지 인용됨**
- 운영 지표 4종: **질문 커버리지율 / 가시성 스코어(Visibility) / SOV / GEO 순위(출처 리스트 내 순위)**

## POV
- "SEO 하던 방식대로 하면 되겠네요" → **절반만 맞다.** 키워드 억지 반복, 분량 채우기, 네이버 카페 같은 폐쇄 공간 축적은 **AI에게 노이즈**
- "AI로 콘텐츠 대량 생산하면 되죠?" → **AI가 AI 글을 학습**하는 오염 구조. 품질 보장 불가 + 브랜드 할루시네이션 유발
- GEO는 **단발성 프로젝트가 아니라 운영형 프로젝트** — 모델 버전이 바뀔 때마다 잘 인용되던 브랜드가 답변에서 빠질 수 있음
- **"광고는 예산이 꺼지면 사라지지만, 한번 만들어둔 브랜드 자산은 계속 쌓인다."**

## 멋사 적용 포인트
- **OM** — 지금 당장 `likelion.net/robots.txt` 확인. 커리큘럼 상세가 **통이미지**로 되어 있으면 AI에게는 존재하지 않는 정보
- **CTS** — 콘텐츠 서두 규칙 변경: 인사말 제거, **첫 2문장에 정의문** 배치. "부트캠프 선택 기준 7가지" 같은 **비교표 콘텐츠**를 우선 생산
- **KDT** — 채널별 USP를 다르게 가져가던 관행 점검. AI는 **채널 관통 일관 메시지**를 요구함
- 즉시 착수 가능한 진단 4영역: 브랜드 포지셔닝 정의 / 유입 채널·데이터 현황 / 콘텐츠 자산 / 기술 인프라

## 핵심 인용
> "AI가 단순히 브랜드 인지도가 높거나 검색량이 아주 높은 브랜드라고 해서 무조건 인용될 수 있다, 이런 식으로 접근하는 것은 절대 안 됩니다."
> "이제는 AI가 우리 브랜드를 잘 이해하고, 또 이들도 널리 알려줄 수 있어야 한다고 생각합니다."

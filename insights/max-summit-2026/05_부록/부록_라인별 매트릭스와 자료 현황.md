### 04 세션별 인사이트 = 데이터베이스로 생성
1. Notion에서 **CSV Import** → `04_세션별-인사이트/session-db.csv` (**37행**)
2. 생성된 DB의 속성 타입 조정
   - 일자 → **Date** / 트랙·L축·원 도메인·게이트 → **Select** / 적용 라인 → **Multi-select** (`;` 구분) / 교차검증 강도·사진 수 → **Number**
   - **v2 주의**: 트랙 Select 값이 `Day1-A` / `Day1-B` / `아침(조찬)` / `2F` / `3F` 5종으로 늘었고, L축 Select 값이 **L5a·L5b로 분리**되었습니다
3. 각 행(세션)을 열어 해당 `.md` 파일 내용을 본문에 붙여넣기
4. **뷰 4개 생성**
   - `L축별` — L1~L5b 그룹화
   - `라인별` — 적용 라인 필터 (브리핑 중 실시간 시연용)
   - `게이트별` — 🟢직접적용만 보기
   - **`강도순`** — 교차검증 강도 내림차순 (v2에서 변별력이 커짐: 3~10 분포)

### 이미지 처리
